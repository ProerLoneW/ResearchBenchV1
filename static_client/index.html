暂未实现的能力（占位说明）

以下功能在本页面不可用，也不会伪造：

功能原因
TeX → 飞书云文档 需要读取你本地磁盘上的 TeX 目录，并完成飞书用户 OAuth 授权。 浏览器沙箱禁止访问本地文件系统，托管服务器也没有你的授权凭据。 请使用完整版 ResearchBench（python -m uvicorn app.main:app）在本机使用。
遍历本地文件夹 / 上传 TeX 仓库 同上。纯网页只能访问用户手动选择的单个文件，无法枚举目录。
AI 总结 / 论文库问答 需要你的模型 API Key。为了避免把 Key 交给托管服务器，本页不调用 AI 接口； 服务端 /api/services/ai/chat 默认关闭（返回 501）。 请在自己的环境里使用主应用的「设置 - API」。
多设备同步 论文库只在本浏览器。可用「导出 / 导入 JSON」手工迁移。
